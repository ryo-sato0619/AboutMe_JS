了解しました！PnP.PowerShellのバージョン1.1.2を使用する前提ですね。

バージョン1.1.2は、現在のPnP.PowerShellの最新版とは異なります。このため、最新版で使える一部のパラメータや機能は、1.1.2では利用できない場合があります。特に認証関連のコマンドは、バージョンアップによって変更されることが多いため、それに留意した上でコマンドをご案内します。

-----

### PnP.PowerShell v1.1.2での監査ログ取得方法

PnP.PowerShell v1.1.2 では、統合監査ログ (`Search-UnifiedAuditLog`) を直接呼び出す専用のコマンドレットは提供されていません。そのため、Microsoft Purview の監査ログを取得するには、**Exchange Online PowerShell (v2モジュール)** を使用する必要があります。これはPnP.PowerShellとは別のモジュールですが、監査ログの取得にはこちらを利用するのが標準的な方法です。

PnP.PowerShellは、主にSharePoint OnlineやMicrosoft Teamsなどの構成管理に特化しており、監査ログの取得はMicrosoft 365のコンプライアンスセンターが提供する基盤（Unified Audit Log）から直接行う形になります。

-----

#### 前提条件: Exchange Online PowerShell v2 モジュールへの接続

監査ログを取得する前に、Exchange Online PowerShell v2 モジュールに接続してください。

1.  **Exchange Online PowerShell v2 モジュールのインストール (まだの場合)**
    管理者としてPowerShellを開き、以下のコマンドを実行します。

    ```powersell
    Install-Module -Name ExchangeOnlineManagement
    ```

2.  **Exchange Online PowerShell への接続**
    以下のコマンドを実行し、Microsoft 365 の管理者アカウントでサインインします。

    ```powershell
    Connect-ExchangeOnline
    # 多要素認証 (MFA) が有効な場合は Connect-ExchangeOnline -UserPrincipalName your.admin.account@yourdomain.com
    ```

    これにより、監査ログの取得に必要な `Search-UnifiedAuditLog` コマンドレットが利用可能になります。

-----

#### 監査ログの取得パターン

##### 1\. URLと期間を指定して監査ログを取得する

特定のSharePointサイトのURLに関連する活動を期間指定で取得するには、`Search-UnifiedAuditLog` でログを取得した後、PowerShellの `Where-Object` を使って**監査データのJSON文字列内にあるURL**をフィルターします。

```powershell
# 期間を指定 (例: 2025年7月1日から7月14日まで)
$startDate = Get-Date -Date "2025-07-01T00:00:00Z"
$endDate = Get-Date -Date "2025-07-14T23:59:59Z"

# 検索したいSharePointサイトのベースURL (例: "https://yourtenant.sharepoint.com/sites/YourSiteName")
$targetSharePointBaseUrl = "https://yourtenant.sharepoint.com/sites/MyProject"

# 監査ログを検索
# SharePoint関連の操作に絞り込むため、WorkloadsとOperationsを指定します。
# PnP.PowerShell 1.1.2 の環境であっても、この部分は Exchange Online PowerShell の機能です。
$auditLogs = Search-UnifiedAuditLog -StartDate $startDate -EndDate $endDate `
    -Workloads "SharePoint" `
    -Operations "FileAccessed", "FileDownloaded", "FileUploaded", "FileDeleted", "PageView", "SharingSet" `
    -ResultSize Unlimited # Unlimited は多くのログを取得する場合に必要ですが、時間がかかります

# 取得したログから、AuditData の JSON 内にある SiteUrl でフィルターします。
# AuditData は JSON 文字列なので、Contains で部分一致を検索します。
$filteredLogs = $auditLogs | Where-Object { $_.AuditData -like "*\"SiteUrl\":\"*$($targetSharePointBaseUrl)*\"*" }

# 結果の表示例 (必要に応じて詳細プロパティを指定してください)
$filteredLogs | Select-Object CreationDate, UserIds, Operations, Workload, @{Name='SiteUrl'; Expression={($_.AuditData | ConvertFrom-Json).SiteUrl}} | Format-Table

# 必要に応じて CSV にエクスポート
# $filteredLogs | Export-Csv -Path "C:\temp\SharePointAuditLog_URL.csv" -NoTypeInformation -Encoding UTF8
```

**重要な注意点**:

  * `AuditData` はJSON形式の文字列として返されるため、その中の特定のプロパティ（例: `SiteUrl`）でフィルターするには、`Where-Object { $_.AuditData -like "*\"SiteUrl\":\"*$($targetSharePointBaseUrl)*\"*" }` のように**文字列としてパターンマッチング**を行う必要があります。`ConvertFrom-Json` を挟むと処理が重くなるため、まずは文字列検索で絞り込み、その後で `Select-Object` 内で `ConvertFrom-Json` を使用して整形するのが効率的です。
  * `Workloads "SharePoint"` と `Operations` パラメータで、関連するアクティビティを絞り込むことが重要です。

##### 2\. Yammerと期間を指定して監査ログを取得する

Yammer (現在の Viva Engage) の監査ログを期間指定で取得するには、`Search-UnifiedAuditLog` の `Workloads` パラメータで `"Yammer"` を指定します。

```powershell
# 期間を指定 (例: 2025年7月1日から7月14日まで)
$startDate = Get-Date -Date "2025-07-01T00:00:00Z"
$endDate = Get-Date -Date "2025-07-14T23:59:59Z"

# Yammer の監査ログを検索
# Yammer 関連の操作をさらに絞り込みたい場合は、Operations パラメータも併用します。
# 例: "MessagePosted", "PostCreated", "MessageReplied", "GroupJoined" など
$yammerLogs = Search-UnifiedAuditLog -StartDate $startDate -EndDate $endDate `
    -Workloads "Yammer" `
    -ResultSize Unlimited

# 結果の表示例
$yammerLogs | Select-Object CreationDate, UserIds, Operations, Workload, @{Name='ObjectId'; Expression={($_.AuditData | ConvertFrom-Json).ObjectId}}, @{Name='OperationName'; Expression={($_.AuditData | ConvertFrom-Json).OperationName}} | Format-Table

# 必要に応じて CSV にエクスポート
# $yammerLogs | Export-Csv -Path "C:\temp\YammerAuditLog.csv" -NoTypeInformation -Encoding UTF8
```

-----

これらのコマンドは、PnP.PowerShellのバージョンに依存せず、Microsoft 365の統合監査ログの基盤に直接問い合わせるものです。PnP.PowerShell v1.1.2の環境でも、Exchange Online PowerShell v2 モジュールがインストール・接続されていれば、上記のコマンドは問題なく実行できるはずです。

# 期間を指定 (例: 2025年7月1日から7月14日まで)
$startDate = Get-Date -Date "2025-07-01T00:00:00Z"
$endDate = Get-Date -Date "2025-07-14T23:59:59Z"

# 検索したいSharePointサイトのベースURL (例: "https://yourtenant.sharepoint.com/sites/YourSiteName")
$targetSharePointBaseUrl = "https://yourtenant.sharepoint.com/sites/MyProject"

# 監査ログを検索
$auditLogs = Search-UnifiedAuditLog -StartDate $startDate -EndDate $endDate `
    -Workloads "SharePoint" `
    -Operations "FileAccessed", "FileDownloaded", "FileUploaded", "FileDeleted", "PageView", "SharingSet" `
    -ResultSize Unlimited # Unlimited は多くのログを取得する場合に必要ですが、時間がかかります

# 取得したログから、AuditData の JSON 内にある SiteUrl でフィルターします。
# AuditData を ConvertFrom-Json でオブジェクトに変換してから、SiteUrl プロパティで比較します。
$filteredLogs = $auditLogs | Where-Object {
    try {
        # AuditData が null でないか、または有効なJSON文字列であるか確認
        $auditDataObj = $_.AuditData | ConvertFrom-Json
        # SiteUrl プロパティが存在し、かつターゲットURLに一致するか確認
        $auditDataObj.SiteUrl -like "*$($targetSharePointBaseUrl)*"
    }
    catch {
        # JSON変換エラーやプロパティが存在しない場合は、このログをスキップ
        $false
    }
}

# 結果の表示例 (必要に応じて詳細プロパティを指定してください)
# ここでも再度 ConvertFrom-Json を使って表示用に整形します。
$filteredLogs | Select-Object CreationDate, UserIds, Operations, Workload, @{Name='SiteUrl'; Expression={($_.AuditData | ConvertFrom-Json).SiteUrl}} | Format-Table
